Aperture is the next chapter of HuyBruh Dash: a quieter, more consistent native dashboard for the Trofeo Vision 9.16″.

Five new layouts — Axis, Ledger, Duet, Orbit and Atelier — join Focus and Grid. Five restrained palettes, a new viewfinder mark, larger gallery previews and a clearer project structure complete the rework.

Download **aperture-windows.zip** for the portable Windows app. “Source code” archives contain no executables. Read `docs/MIGRATION.md` before upgrading, and preserve your existing `trofeo.conf`.

The display program is now `aperture-display.exe`; settings are now `aperture.exe`. Existing layout/palette keys remain compatible, while `all` now cycles the curated collection.

Native previews use sample data. See `docs/VALIDATION.md` for build/test evidence and physical-panel coverage. Older CPU/RAM benchmark numbers are not claims about this release.
