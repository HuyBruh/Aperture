# Aperture design system

The mark is a split viewfinder with a diagonal opening. It is a vector construction, not an HB monogram or gradient badge. `assets/brand/mark.svg` is the source; raster icons are generated by `tools/make-brand.py`.

## Screen grammar

- Reference canvas: 1920 × 462. Outer inset: 24 px. Panel gap: 16 px. Inner padding: 20 px. Corner radius: 16 px.
- Inter for the collection, including Focus. Numbers stay neutral; headings use the accent. Units are smaller and attached to their values.
- Hero cap heights: 64–112 px, dependent on the composition. Detail cap heights: 30–38 px. Labels: 12–14 px.
- A six-reading CPU/GPU/memory model is shared with Grid. Layouts arrange this model, not a subset of it. Hotspot stays visible in the GPU header; FPS and VRAM are separate readings.
- Thin history lines appear only where they fit below a hero. They do not take the place of readings.
- Full titles use the existing marquee renderer. Device names, artist names and weather labels are bounded and ellipsized.
- No animated wallpaper or automatic song popup in fresh defaults. These remain configurable.

## Color

Mineral, Frost, Blush, Sand and Iris each use one coordinated accent. Text, muted text and labels meet a minimum 4.5:1 contrast against their specified panel color. Warnings retain the renderer's temperature semantics. Existing color keys remain accepted for old configurations.

`design/collection.json` owns layout geometry and palette reference colors. Run `python tools/generate-design.py` after changing the geometry, and `python tools/check-design.py` before building. Native sample renders must still be inspected: geometric checks cannot catch every glyph collision.

The settings app separates the new collection from legacy landscape layouts, uses larger two-column thumbnails and the same brand accent. Old configurations are not silently rewritten on launch.
