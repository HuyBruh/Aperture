# Customize an existing theme

1. Open Layouts and choose Axis, Ledger, Duet, Orbit, Atelier, Panorama or Cinema.
2. Click Customize selected theme to edit a copy of the supplied arrangement.
3. Select a panel in the preview or use the panel buttons below it. Drag to move;
   use the corner handle to resize. Position and size contains optional coordinates.
4. Toggle individual readings, change text color, or adjust Reading text size.
5. Choose an image/GIF background. The preview uses sample data and one GIF frame;
   the physical display plays the animation.
6. Restore original theme returns to the supplied layout. Presets save your edits
   separately from personal sensor and weather settings.

Panel editing supports the seven Aperture layouts listed above. Focus, Grid,
portrait and legacy layouts remain selectable but have no editable panel geometry.

Free canvas is optional: build from individual readings using 26 content types,
up to 48 widgets, snapping, colors, text size, duplicate/delete and panels.
Backgrounds are copied into assets/backgrounds. On another PC, choose the background
again after importing a preset. Physical GPU selection and asset bundling remain
in development. Selecting a widget reading does not select a physical GPU.
